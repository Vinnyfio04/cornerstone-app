# Exercise ambience

This ambience plays only while the guided breathing activity is active. The
source identifies the file as Creative Commons Zero (CC0), so it may be copied,
adapted, and included in the application.

- `gentle-wind-chimes.mp3`: “Wind Chimes 02.wav” by Adelantemos, Freesound ID
  222893. The creator describes it as a completely wind-driven recording of
  rich, deeper chimes with a soft wooden hammer.
  - Original source: https://freesound.org/people/Adelantemos/sounds/222893/
- License: https://creativecommons.org/publicdomain/zero/1.0/

The application plays the file at its original browser playback rate of 1×.
It does not slow, speed, pitch-shift, or otherwise time-stretch the recording.
The 76-second ambience starts when the activity begins, loops if needed, and
stops and rewinds as soon as the activity is no longer active.
