# 01 — Bounded Scaffold

Use this prompt to create or review the repository's initial documentation-only structure before application development.

```text
Read AGENTS.md and any existing README.md before changing files. Work only inside the Cornerstone project root.

Create or repair only the bounded initial scaffold: backend/, frontend/, docs/, README.md, AGENTS.md, and .gitignore. Document the Python/FastAPI backend, Vue frontend, project-owned environments, separation boundaries, known commands, and unresolved decisions. Establish durable permission, dependency, process, and reporting rules in AGENTS.md.

Ignore generated Python environments and caches, Node dependencies, Vue/Vite output, environment files, editor files, logs, and operating-system artifacts. Preserve dependency manifests and lockfiles.

Do not create environments, install dependencies, initialize Git, or write application features. Ask a targeted question only if missing information would materially change this scaffold. Report every created or modified path and every check performed, then stop.
```
